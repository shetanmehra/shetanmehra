### 🚀 About Me

I am an **AI Software Engineer** and self-taught developer specializing in layered AI agent ecosystems. My journey began by reverse-engineering APKs on mobile devices before owning a laptop, fostering a deep understanding of system internals and security.

- 🔭 **Currently Building:** [**Agent Studio**](https://github.com/shetanmehra/agent-studio) — An open-source, node-based AI agent orchestration platform.
- 📦 **Developer Tools:** Maintaining **agentsdk-js** (MIT) and an AI-powered Website Builder.
- 🎯 **Mission:** Democratizing access to advanced AI tooling for developers and students.
- 🌱 **Deepening Expertise:** AI Agent Architecture, Secure Sandboxing (Kata/K3s), and Distributed System Design.
- ⚡ **Fun Fact:** I learned to code by decompiling apps long before I wrote my first "Hello World."
