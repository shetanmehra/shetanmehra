## 🚀 About Me

I'm a **solo founder & AI agent developer** building a layered AI agent ecosystem — from a closed, monetized meta-agent engine down to a fully open-source developer SDK. I'm self-taught: started by reverse-engineering APKs on my phone before I even owned a laptop, and I've been building ever since.

- 🔭 Currently building **Agent Studio** (open-source AI agent orchestration) and a **Meta-Agent Engine** (containerized, secure multi-agent runtime)
- 🌱 Deep in **AI agent architecture, system design, and secure sandboxing**
- 🎯 Mission: build affordable, accessible AI tools for developers and students
- ⚡ Fun fact: learned to code by reverse-engineering apps before owning a laptop
